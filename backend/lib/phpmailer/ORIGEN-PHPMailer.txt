PHPMailer
=========

Librería para mandar correos desde PHP (SMTP, codificación MIME, texto plano
y HTML). El backend la usa para enviarle a cada estudiante el enlace de una
actividad al asignarla (HU-019, config/correo_envio.php).

Se incluye en el proyecto en lugar de instalarla con Composer. Se cargan los
tres archivos con require_once (sin autoload). No se edita: para
actualizarla, se reemplazan los cuatro archivos por los de otro tag y se
actualizan estos datos. .gitattributes evita que git les cambie los fines de
línea. ../.htaccess impide pedirlos por web.
